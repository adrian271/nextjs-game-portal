Gameplay Stats — Two Architectures

Tracking RPS win/loss/draw and Tic-Tac-Toe X/O wins, per user account

Approach A · Simple

Counter columns + Server Actions — fewest moving parts
Write path — recording a result
🎮 Game (Client Component)
Round ends → calls a function directly
↓ calls recordResult(outcome)
⚙️ Server Action 'use server'
Identity from auth() — client can't spoof user
↓ upsert + atomic increment
🗄️ GameStats row (Postgres)
rpsWins / rpsLosses / rpsDraws / tttXWins / tttOWins
Read path — showing totals
📄 Game page (Server Component)
↓ findUnique (one tiny query)
🗄️ GameStats row
The totals are the row — nothing to compute
＋ Minimal code, one round-trip, trivial to verify in Supabase
＋ Teaches upsert + race-safe atomic increment
－ No history (only current totals); new stat = new column + migration

Approach B · Ōura-shaped Hybrid

Event log + precomputed counter read-model, behind a service endpoint
Write path — recording a result
🎮 Game (Client Component)
Round ends → fetch POST
↓ POST /api/stats (HTTP service boundary)
⚙️ API Route (service)
auth() + validate body (Zod)
↓ one Prisma $transaction
ATOMIC — both succeed or neither
📜 GameResult
append-only event
(game, outcome, time) — history
🗄️ GameStats
counter read-model
incremented on write
Read path — showing totals
📄 Game page
↓ read precomputed counters (fast)
🗄️ GameStats (read-model)
⤷ at scale, cache here
⚡ Redis (cache) — not built, just where it'd go
＋ Full history (streaks, "last 10", leaderboards) for free
＋ Precompute-on-write discipline — the core NoSQL/event lesson
－ More code: transaction, event table + index, explicit endpoint

How this maps to the Ōura stack (from the posting)

API Route≈ API Gateway → AWS Lambda (Service-Oriented Architecture)
GameResult log≈ DynamoDB item appends + Streams (event-driven)
GameStats counters≈ precomputed aggregate (DynamoDB has no GROUP BY → totals maintained on write)
Redis cache= Redis (atomic INCR / sorted-set leaderboards)
$transaction≈ stream-maintained consistency between event + aggregate
Client / browser Server logic (auth) Counter read-model Append-only event log Read path Cache (not built)
